# Security

Report a vulnerability privately with [Report a vulnerability](https://github.com/VaibhavAcharya/stateofpixel/security/advisories/new) on this repo, or by email to hello@stateofpixel.com. Do not open a public issue for it.

Fixes go to stateofpixel.com and to the latest `stateofpixel` release on npm.
