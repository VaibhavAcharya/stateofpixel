## Authentication

On GitHub Actions the CLI uses the OIDC token, which needs `permissions: id-token: write`. Anywhere else, set `STATEOFPIXEL_TOKEN` to a project token. See [Other CI](/docs/other-ci).

## Exit codes

- **0** when the build was reported, with or without changes. The GitHub check decides whether the pull request can merge.
- **0** with a warning when stateofpixel is down or a rate limit is hit, so an outage does not break your CI. Pass `--strict` to exit 1 instead.
- **1** on configuration and authentication errors, failed uploads, and images over the [limits](/docs/limits).
